How the Algorithms Work

Greedy: creates all 48 sessions (24 per batch), sorts them so labs and heavy subjects go first, and for each one picks the best valid (day, period, room) by a simple score (least busy day, least used room). It never undoes a decision; if no valid place exists it reports failure.

Backtracking: places sessions one by one using the same constraint check. If a session has no valid slot, it goes back, removes the previous placement and tries another slot or room, until every session is placed or all options are exhausted.

Shared checks: a teacher, room or batch can hold only one session per slot, and A1/A2 never have the same subject at the same time. Teacher-to-subject mapping is identical for both batches.
